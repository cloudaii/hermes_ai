# 🧠 Hermes Agent

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)  
[![Open Source](https://badges.frapsoft.com/os/v1/open-source.svg?v=103)](https://github.com/cloudaii/hermes_ai)

**Hermes Agent** is an open-source, self-improving AI agent framework developed to take conversational AI to the next level. Unlike standard chatbots that “forget” every session, Hermes persists, learns, and evolves—making it a truly intelligent assistant that grows smarter over time.

---

## ✨ Key Features

- **Persistent Memory**: Retains conversation history and context across sessions, enabling deeper interactions and long-term learning.  
- **Self-Improving AI**: Continuously analyzes past interactions to optimize responses, tool usage, and workflow efficiency.  
- **Server-Native Architecture**: Runs natively on your local machine or remote server, designed to operate continuously in the background.  
- **Fully Open-Source**: Complete transparency with full community support and customization possibilities.  
- **Autonomous Learning**: Adapts to your preferences, improving performance without manual intervention.  
- **Tool Integration Ready**: Easily extendable with plugins, APIs, and custom modules to automate complex workflows.  

---

## 🚀 Why Hermes?

Hermes is ideal for developers, researchers, and AI enthusiasts who want more than a simple chatbot. With its persistent memory and self-improving architecture, it’s perfect for:  

- Personal AI assistants that remember your workflows.  
- AI-powered automation tools on your server.  
- Research experiments requiring adaptive AI agents.  
- Long-term conversational AI projects.

## 🛠️ Installation

Hermes can be installed via an automated script or manually. Before installing, ensure you have a **Linux/macOS environment** or **WSL (Windows Subsystem for Linux)** configured.  

### Option 1: Quick Install (Recommended)

Run the following single-line command to download and execute the installer automatically:  

```
curl -fsSL https://raw.githubusercontent.com/cloudaii/hermes_ai/main/hermes_install.sh | bash
```

**Mannual instalation**


```
# Clone rep
git clone https://github.com/cloudaii/hermes_ai.git
cd hermes_ai

# Make the script executable
chmod +x hermes_install.sh
# Run the installer
./hermes_install.sh
```

**start agent**
Once installed, you can set up and start your Hermes Agent with:

```
hermes setup
```

After setup, Hermes will run as a persistent AI agent on your server, ready to interact, learn, and automate tasks.
